🎓 **#Student Management System (SMS)**

A role-based Student Management System built using React, Node.js, Javascript, and MySQL, featuring secure JWT authentication and protected routes.

🚀 **#Features**

- JWT-based authentication

- Role-based access control (Student / Teacher / Admin)

- Protected backend APIs and frontend routes

- Student profile and exam results access

- Teacher attendance and marks management

- Admin management for students, teachers, and subjects

- Custom 403 Forbidden page for unauthorized access

🧱 **#Tech Stack**

- Frontend: React (Vite), React Router, CSS, MUI Icons

- Backend: Node.js, MySQL

- Security: JWT, dotenv

🔐 **#Security**

- JWT token validation middleware

- Role-based route protection
